# Internal Operations App

This app is now scaffolded as a React + Vite frontend focused on LLM-assisted document generation for internal operations.

Current surface:
- Single-screen landing and workspace flow
- Featured generator cards for tender, financial report, PPTX, and ops memo drafting
- In-place structured inputs, generation state, draft preview, and export actions
